# Projeto Final Front-End - Open Finance

Este projeto é uma aplicação front-end desenvolvida para o projeto final de estágio relacionado ao Open Finance.

## Tecnologias Utilizadas

-   **React** (v19.2.0)
-   **React Router DOM** (v7.9.4)
-   **Axios** (v1.12.2)
-   **React Icons** (v5.5.0)
-   **CSS Modules**
